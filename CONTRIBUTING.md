# Contributing

This repository is the public GitHub profile surface for **Brittek Digital**.
It is not a general-purpose application repository.

## Scope

Contributions are appropriate when they improve:

- profile accessibility or rendering;
- workflow reliability or supply-chain hygiene;
- generated profile telemetry;
- broken links or asset references;
- machine-readable metadata;
- documentation accuracy.

Brand positioning, commercial language, visual identity, and canonical
technical claims remain governed by Brittek Digital.

## Before opening a pull request

1. Keep the change narrowly scoped.
2. Do not replace pinned GitHub Actions with floating version tags.
3. Do not add trackers, analytics, visitor counters, or unnecessary external
   runtime dependencies.
4. Verify Markdown renders correctly in GitHub light and dark themes.
5. Preserve reduced-motion and accessibility considerations where relevant.
6. Do not expose private repository, client, account, credential, or
   infrastructure details.

## Pull requests

A useful pull request should include:

- what changed;
- why it improves the profile surface;
- how the change was verified;
- screenshots for visible presentation changes;
- any new external dependency introduced.

## Issues

Issues may be used for reproducible defects in the public profile surface or
automation. Commercial enquiries should use <https://brittek.net> or
<mailto:hello@brittek.net>.
